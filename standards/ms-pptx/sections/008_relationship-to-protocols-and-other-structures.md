## Relationship to Protocols and Other Structures


The structures described in this document are incorporated into PresentationML documents as described in [[ISO/IEC29500-1:2016]](https://go.microsoft.com/fwlink/?linkid=861065) using the Markup Compatibility and Extensibility features as described in [[ISO/IEC29500-3:2015]](https://go.microsoft.com/fwlink/?linkid=861154). The global elements described in this format appear as optional child elements of certain elements described in [ISO/IEC29500-1:2016] as described in section [2.3](#Section_6c8fa8193ae640e4af4c83abfd44b381). The global attributes described in this format appear as optional attributes on certain elements described in [ISO/IEC29500-1:2016] as described in section [2.4](#Section_b0b9a1acb87146d889c969e75ea316e5). Some of the elements, attributes, simple types and complex types here also refer to complex or simple types described in [[ISO/IEC29500-4:2016]](https://go.microsoft.com/fwlink/?linkid=861068).
