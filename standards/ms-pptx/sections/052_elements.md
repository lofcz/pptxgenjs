### Elements


#### <a id="section_465ea8114e454288a783bef4b9ec6eec"></a><a id="_Toc174685964"></a>designElem

*Target namespace: *http://schemas.microsoft.com/office/powerpoint/2015/main

<a id="CC_07da481a000000000000000000000000"></a>A [CT_DesignElement](#Section_208645d6756f4479a3d2249ebd379d28) element (section 2.5.3.1) that specifies whether an item is a design element. See section 2.5.3.1 for how this element integrates with [[ISO/IEC29500-1:2016]](https://go.microsoft.com/fwlink/?linkid=861065).

The following W3C XML Schema ([[XMLSCHEMA1/2]](https://go.microsoft.com/fwlink/?LinkId=90607) section 2.1) fragment specifies the contents of this element.

1. <xsd:element name="designElem" type="CT_DesignElement"/>

See section [5.6](#Section_166486237c2a4c18a7cb093daa05500e) for the full W3C XML Schema ([XMLSCHEMA1/2] section 2.1).
