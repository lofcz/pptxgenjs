## Extensions


This section specifies the elements from [[ISO/IEC29500-1:2016]](https://go.microsoft.com/fwlink/?linkid=861065) that are extended by this format. Either the __Ignorable__ attribute ([[ISO/IEC29500-3:2015]](https://go.microsoft.com/fwlink/?linkid=861154) section 7.2), __AlternateContent__ element ([ISO/IEC29500-3:2015] section 7.5), or the __extLst__ element ([ISO/IEC29500-1:2016] section 19.2.1.12) MUST be used to maintain compatibility with [ISO/IEC29500-1:2016] implementations.
