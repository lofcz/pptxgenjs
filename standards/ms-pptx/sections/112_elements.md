### Elements


#### <a id="section_4f40bd5c5ad24657b4f0d67a082cb634"></a><a id="_Toc174686115"></a>designPr

*Target namespace: *http://schemas.microsoft.com/office/powerpoint/2020/02/main

<a id="CC_04350b5f000000000000000000000000"></a>A [CT_DesignerDrawingProps](#Section_979b46d1d6474750a8473d59e27675d3) element that specifies designer properties of a shape object. See section 2.17.3.1 for how this element integrates with [[ISO/IEC29500-1:2016]](https://go.microsoft.com/fwlink/?linkid=861065).

The following W3C XML Schema ([[XMLSCHEMA1/2]](https://go.microsoft.com/fwlink/?LinkId=90607) section 2.1) fragment specifies the contents of this element.

1. <xsd:element name="designPr" type="CT_DesignerDrawingProps"/>

See section [5.16](#Section_e68b6b1996544d2b929a0860e37ce25d) for the full W3C XML Schema ([XMLSCHEMA1/2] section 2.1).
